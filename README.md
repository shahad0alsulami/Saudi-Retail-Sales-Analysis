# Saudi Retail Sales Analysis

## Project Overview
A retail sales analytics project using Microsoft Excel to explore sales performance, profitability, and business trends in Saudi Arabia.

## Tools
Microsoft Excel, Data Cleaning, Pivot Tables, Data Visualization.

## Analysis Areas
- Total sales and profitability
- Sales by product category
- Regional and city-level performance
- Product performance
- Payment method distribution

## Project Goal
Transform retail transaction data into insights that support sales monitoring and business decision-making.
